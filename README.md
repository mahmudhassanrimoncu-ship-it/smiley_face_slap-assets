# How to Measure with a Screw Gauge – narrated explainer

An ~8-minute animated lesson with voice narration and on-screen captions. It shows how to use a micrometer screw gauge.

**Video:** [`video/how-to-use-a-screw-gauge.mp4`](video/how-to-use-a-screw-gauge.mp4) (1920×1080, 30 fps, AAC narration)

## Contents
1. Intro: why a screw gauge (0.01 mm) beats a metre rule (1 mm) and a vernier caliper (0.1 mm)
2. Parts: frame, anvil, spindle, sleeve and main scale, thimble and circular scale, ratchet, lock nut
3. Pitch: 4 turns move the spindle 2 mm, so pitch = 0.5 mm
4. Least count: 0.5 mm ÷ 50 divisions = 0.01 mm
5. Zero error: none, positive (+0.03 mm) and negative (−0.03 mm); corrected = observed − zero error
6. Worked example, wire diameter: MSR 2.5 mm + CSR 38 × 0.01 = 2.88 mm, minus 0.03 = **2.85 mm**
7. Pause-and-try practice, sheet thickness: 1.12 − (−0.02) = **1.14 mm**
8. Repeat at several places, two readings at 90° each, then take the mean
9. Precautions (ratchet, backlash, clean faces, zero error, parallax, averaging)
10. Summary formula card

## Re-rendering
Everything is generated by [`screw-gauge/make_video.py`](screw-gauge/make_video.py): Pillow draws the frames, Piper TTS reads the narration and ffmpeg encodes the MP4.
```bash
pip install pillow numpy piper-tts
# voice files: en_US-lessac-medium.onnx + .onnx.json from huggingface.co/rhasspy/piper-voices
PIPER_VOICE=~/voices/en_US-lessac-medium.onnx python3 screw-gauge/make_video.py
python3 screw-gauge/make_video.py --preview 3 --scene 6   # PNG stills every 3 s of scene 6
```

# How a Refrigerator Works – animated explainer

An ~11.5-minute animated lesson built with [Canvas Commons](https://canvascommons.io/) that explains the vapour-compression refrigeration cycle, with built-in "pause & think" quizzes and a final 6-question test.

**Video:** [`video/how-a-refrigerator-works.mp4`](video/how-a-refrigerator-works.mp4) (1920×1080, 30 fps, no audio)

## Contents
1. Intro – heat flows hot → cold by itself; a fridge moves it the other way using work
2. The sealed loop and its 4 parts, high- vs low-pressure sides, liquid/gas key
3. Evaporator · 4. Compressor · 5. Condenser · 6. Expansion valve (each with pressure/temperature meters and a quiz)
7. Energy balance: Qout = Qin + Win, COP
8. Myth buster: why an open fridge door warms the kitchen
9. Final test + summary

## Editing / re-rendering
```bash
npm install
npm start          # opens the Canvas Commons editor at http://localhost:9000
```
Press **RENDER** in the editor (image sequence → `output/`), then:
```bash
ffmpeg -framerate 30 -i output/how-a-refrigerator-works/%06d.jpeg \
  -c:v libx264 -crf 22 -pix_fmt yuv420p video/how-a-refrigerator-works.mp4
```
